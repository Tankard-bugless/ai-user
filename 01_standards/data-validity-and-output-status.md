# 问卷数据有效性与输出状态

## 1. 目的

本规范固定一条简单主线：

> 设计问卷时同时定义变量、编码、缺失和有效性信号；答卷返回后只按预先定义的规则判定单份答卷状态和整体数据集状态。

问卷不是先收集一堆答案、分析时再临时决定口径。InstrumentSpec 是题目与数据结构的共同契约，FieldworkPackage 记录规则实际执行后的结果。

## 2. 两层职责

### 2.1 工具设计时

研究工具设计专家必须为每道题定义：

- 稳定的 `item_id` 与 `variable_name`。
- 题型、选项值、是否必答、适用人群和跳转。
- 正常作答值，以及“不知道/不确定”“不适用”“不愿回答”等特殊值的含义。
- 结构性空缺、题目缺失和选答空白的区分。
- 该变量属于甄别、主要结果、分群、知识、质量信号还是开放文本。
- 单份答卷硬排除规则、人工复核信号和整体数据输出状态。

### 2.2 数据返回后

执行或分析环节只负责：

1. 核对问卷版本、字段和选项值。
2. 按预设规则给每份记录赋状态与原因码。
3. 解决所有 `REVIEW_REQUIRED` 记录。
4. 汇总题目缺失、子组基数和已知限制。
5. 输出整体数据集状态。

不得在看到结果后为了获得更“好看”的结论新增排除规则、改分群或改变知识题答案。

## 3. 题目级值口径

| 值状态 | 含义 | 是否为有效研究信息 |
|---|---|---|
| `SUBSTANTIVE` | 正常选项、文本或数值 | 是 |
| `UNKNOWN` | 不知道、不确定、记不清 | 是；知识题中可计为未答对，但不能视为无效答卷 |
| `NOT_APPLICABLE` | 题目对该参与者不适用 | 是；不进入该题适用分母 |
| `PREFER_NOT_TO_SAY` | 参与者明确不愿回答 | 是；保留为独立类别，不据此排除答卷 |
| `STRUCTURAL_MISSING` | 因合法跳转未展示题目 | 是；不算题目漏答 |
| `ITEM_MISSING` | 题目应展示但没有答案 | 否；计入题目缺失，但不自动导致整份答卷无效 |

年龄题中的“不愿回答”、知识题中的“不确定”和行为题中的“记不清”都是研究结果。它们不能被当作低质量作答信号。

## 4. 单份答卷状态

| 状态 | 含义 | 主分析处理 |
|---|---|---|
| `UNASSESSED` | 已导入但尚未执行质量规则 | 不进入冻结数据集 |
| `VALID` | 满足同意和目标人群要求，且无未解决质量问题 | 纳入 |
| `REVIEW_REQUIRED` | 出现一个或多个可疑信号，但不足以自动判为无效 | 暂不冻结；人工复核后转为 `VALID` 或 `EXCLUDED` |
| `EXCLUDED` | 命中确定性排除规则，或人工确认不应进入分析 | 不纳入；保留原因和决定记录 |

一个记录只能有一个当前状态，但可以有多个原因码。状态变更必须保留原状态、原因、决定人和时间。

### 4.1 硬排除原因码

| 原因码 | 规则 |
|---|---|
| `CONSENT_NOT_GIVEN` | 未同意研究说明或同意字段缺失 |
| `INELIGIBLE` | 明确表示从未购买养老目标基金 |
| `NO_SUBSTANTIVE_DATA` | 除同意/甄别外，所有核心模块均无正常作答或有效特殊值 |
| `SCHEMA_OR_VERSION_ERROR` | 记录无法对应批准的问卷版本、字段或选项值，且无法可靠修复 |
| `CONFIRMED_DUPLICATE` | 人工确认与另一记录为重复提交；保留预先指定的一份 |

### 4.2 只触发复核的原因码

| 原因码 | 规则 |
|---|---|
| `ELIGIBILITY_UNCERTAIN` | 回答者不确定自己是否购买过养老目标基金 |
| `SPEEDING_SUSPECTED` | 有完成时长时，且至少已有 30 份完成记录，时长低于当批完成记录中位数的三分之一 |
| `LOGIC_CONFLICT` | 两道本应一致的事实或路由字段出现无法由题意解释的冲突 |
| `DUPLICATE_SUSPECTED` | 匿名记录出现高度相似的提交信息或作答模式，但尚未人工确认 |
| `HIGH_ITEM_MISSINGNESS` | 应展示的核心题目中，`ITEM_MISSING` 比例超过 20% |

单个可疑信号不得自动删除答卷。尤其是答题快、答案相同、知识题答错、选择“不确定”或不填开放题，都不能单独成为排除依据。

## 5. 整体数据集状态

| 状态 | 条件 | 是否可进入洞察分析 |
|---|---|---|
| `ANALYSIS_READY` | 版本和字段通过；所有记录已定为 `VALID`/`EXCLUDED`；分母、缺失和排除已汇总；无重要限制 | 是 |
| `ANALYSIS_READY_WITH_LIMITS` | 满足冻结条件，但存在非阻断限制，例如样本来源集中、年龄子组过小或关键题缺失偏高 | 是；报告必须披露限制 |
| `BLOCKED` | 仍有 `UNASSESSED`/`REVIEW_REQUIRED`，或字段版本、核心路由、同意、排除记录无法核对 | 否；返回数据整理或工具阶段 |

整体状态不是“这批样本代表总体”的认证。当前 Demo 没有概率抽样框，因此即使为 `ANALYSIS_READY`，也只描述本次有效答卷。

## 6. 分母与分群输出

- 主样本数：`VALID` 记录数。
- 题目有效分母：主样本中该题适用，且值状态为 `SUBSTANTIVE`、`UNKNOWN` 或 `PREFER_NOT_TO_SAY` 的记录数。
- `STRUCTURAL_MISSING` 和 `NOT_APPLICABLE` 不进入该题分母；`ITEM_MISSING` 单独报告。
- 多选题选择率以该题有效回答人数为分母。
- 知识题须同时报告正确、错误和不确定，不把“不确定”从分母中静默删除。

当前 Demo 的年龄分群使用轻量展示规则：

- `n < 10`：不单独展示比例；可在有业务意义时合并相邻年龄段，否则标为“样本不足”。
- `10 ≤ n < 20`：可展示人数和比例，但必须标注“小样本，仅供方向观察”。
- `n ≥ 20`：可做描述性比例比较，仍不得解释为总体差异、显著性或因果关系。

这些阈值是内部报告护栏，不是统计代表性标准，也不能替代抽样设计和不响应评估。

## 7. 最小输出结构

单份答卷质量表至少包含：

- `record_id`
- `instrument_id` 与 `instrument_version`
- `response_status`
- `reason_codes`
- `included_in_main_analysis`
- `reviewed_by`、`reviewed_at`、`review_note`（触发复核或排除时）

数据集质量摘要至少包含：

- 各答卷状态数量
- 各原因码数量
- `VALID` 主样本数
- 题目级适用分母与缺失
- 年龄子组基数和展示状态
- 整体 `dataset_status`
- 限制和阻断原因

## 8. Gate 规则

Gate 2 必须确认：

- InstrumentSpec 已定义变量、特殊值、结构性空缺、硬排除和复核信号。
- 知识题答错、不确定和画像拒答不会被误写为无效答卷。
- 平台 Adapter 不改变变量语义和状态规则。

Gate 3 必须确认：

- 所有记录状态已解决，排除可追溯。
- 数据集为 `ANALYSIS_READY` 或 `ANALYSIS_READY_WITH_LIMITS`。
- 报告分母、缺失、年龄子组和限制与 FieldworkPackage 一致。

## 9. 方法依据与适用边界

- AAPOR《Standard Definitions》用于参考“资格、完成、未完成和未知资格必须区分，处置状态应标准化”的原则。
- Government Analysis Function 的问卷与调查开发指引用于参考“数据需求从设计开始定义，以及分别检查不知道、拒答、跳转空缺和题目缺失”的原则。
- 当前规则为企业内部用户研究 Demo 的轻量实现，不直接声称符合任何官方统计调查认证，也不计算无法由现有投放信息支持的总体响应率。
