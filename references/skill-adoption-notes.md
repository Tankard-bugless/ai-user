# Skill 采用说明

本文件记录外部 Skill 对核心架构产生的实际影响。Skill 是方法参考，不是本项目的权威口径；发生冲突时，以 `01_standards` 为准。

## interview-research

本轮复核了：

- `interview-research/SKILL.md`
- `references/phase1-guide.md`
- `references/phase2-recruitment.md`
- `references/phase4-transcript.md`
- `references/phase5-report.md`

### 已采用

- 访谈优先询问最近发生的具体行为，而不是只问抽象态度。
- 每个主问题包含追问、关键探查点和意外回答的跟进路径。
- InstrumentSpec 中增加主持人备忘录，包括优先话题、备用追问、时间分配、偏差警示和应寻找的证据。
- 招募设计区分必要条件、加分条件、排除条件和配额。
- RecruitmentPlan 增加证据核验、替补规则和供应商交付清单。
- 收尾环节保留开放补充和后续联系许可。
- FieldworkPackage 保存脱敏逐字稿、主持人笔记、录音或资料索引、执行偏离与质量信息，不把摘要当作原始资料。
- InsightPackage 中的原话必须保留参与者编号和行号、时间戳或段落定位；听不清的内容明确标记，不根据上下文补写。
- 分析同时寻找行为、态度、替代做法和与主要模式矛盾的案例。
- 报告建议通过 Insight 和 Finding 回溯至 Evidence Unit，并明确样本范围、限制和待验证项。

### 调整后采用

- Skill 建议保留生动原话；本项目要求原话逐字保存，同时必须保留参与者编号和来源定位，不允许 AI 美化后继续标为原话。
- Skill 将替代方案视为重要需求信号；本项目将其作为需要编码和追问的重要证据，但不会直接升级为需求或产品建议。
- Skill 建议精炼核心发现；本项目不预设统一发现数量，实际数量由研究问题和证据决定。

### 未采用或被项目规则覆盖

- Skill 的默认实名模式不适用于本项目。项目继续执行默认脱敏、最小数据使用和联系信息分离。
- 不要求参与者提供持仓、资产或账户截图来证明研究资格；核验强度必须与研究风险和最小数据原则匹配。
- Skill 的阶段路由不直接作为多 Agent 状态机；正式工作流仍以 Artifact、Schema 和四个 Gate 驱动。

## skill-creator

本轮复核了 `skill-creator/SKILL.md`，用于设计专家能力卡未来封装为可运行 Skill 的方式。

### 已采用

- 能力卡名称使用简短、动词开头的 hyphen-case 建议名。
- 核心职责、触发条件和工作流规则保持简洁；问卷、访谈、定性和定量方法放入按需加载的参考模块。
- 稳定、重复且容易出错的结构与引用检查交给确定性脚本，不要求模型每次重新推理。
- 每张能力卡后续必须包含正向、边界、对抗和回归测试案例。

### 当前未执行

- 本轮只生成项目内的能力卡总览，没有初始化可安装 Skill；待逐张能力卡内容确认并确定安装位置后再执行 Skill 初始化与验证。

## ima-skill

本轮完整复核了 `ima-skill/SKILL.md`、知识库子技能和 API 参考，并对 IMA 知识库「易方达基金」执行了只读检索。

### 当前采用

- 保留 IMA 知识库人工链接作为核心测量后的可选学习入口。
- 保留未来 `IMAAdapter` 的搜索、问答、正文解析和链接健康检查契约。
- 不新增 IMA 专家 Agent，也不让平台接口改变 ResearchBrief、ResearchPlan 或 InstrumentSpec 的核心语义。

### 能力验证结果

- 可按“养老目标基金、目标日期基金、目标风险基金、下滑曲线、Y份额、FOF”等关键词取得相关标题。
- 当前订阅知识库不允许通过 Skill 读取条目全文，因此本轮状态为 `TITLE_ONLY`。
- 当前无法解析稳定文章直链，采用知识库首页、准确标题和搜索词作为降级路径。
- SkillHub 安装的 `ima-skills 1.1.8` 与既有 `ima-skill 1.1.8` 逐文件一致，没有新增知识库自然语言问答接口。

### 当前不启用

- `ima_api_status=RESERVED_DISABLED`，CAP-03 默认不得调用 IMA OpenAPI。
- IMA 接口输出不进入金融事实审核、AI 解释来源或 Gate 2 必需输入。
- 金融知识继续由监管文件、产品法律文件和领域事实库复核。
- 仅搜到标题时不得把 AI 解释标注为“来源于 IMA”；当前统一不使用该来源标注。
- 客观知识题必须先测后教；解释放在回答后、模块后或完成页。
- 已安装 Skill 作为未来能力储备保留，不向 IMA 上传、修改或删除内容。

### 重新启用条件

- 当前 Agent 环境可直接读取订阅知识库正文或完成知识库问答。
- 返回结果具备可核验来源和稳定链接。
- 权限、安全、失败降级和来源冲突测试通过。
- 研究负责人批准新的 IMA 接入规范版本。

## codex-claude-academic-skills

本轮从 `zLanqing/codex-claude-academic-skills` 定向安装并复核了 `research-writing-skill` 和 `office-academic-skill`，没有把整个仓库直接并入工作流。

### 已采用

- 报告先明确读者、决策任务和证据边界，再设计章节结构。
- 标题优先承载判断，正文使用“主张—证据—含义—边界”的论证单元。
- 数据、图表和引用必须回到可复核来源，不以顺畅叙事覆盖反例或限制。
- Word 交付件使用版本化文件名、稳定标题层级、图题和表题，并在最终尺寸逐页渲染复核。

### 调整后采用

- 本项目是业务用户研究报告，不是学术论文；保留严谨论证和来源纪律，但不强制摘要—文献综述—方法—讨论等期刊结构。
- 管理层报告允许短段落、要点和执行卡片，只要没有压缩掉样本边界、证据强度和待验证项。
- 不强制双语、期刊格式或特定引文体例；组织模板和 ResearchReport Schema 优先。

## scientific-agent-skills

本轮从 `K-Dense-AI/scientific-agent-skills` 定向安装并复核了 `scientific-visualization`。

### 已采用

- 按比较、构成、趋势、分群等分析任务选择图形，不把装饰性复杂度当作专业度。
- 条形图从零开始，避免 3D、双轴误导和不一致尺度；关键数字直接标注。
- 使用克制且可区分的配色，颜色不是唯一编码，并为图表提供图注和替代文本。
- 非嵌套指标不画成漏斗；实际行为、提示后自报、知识正确率和偏好信号分开呈现。
- 每张图保存来源、筛选、变换、生成文件和完整性说明，形成机器可读的 figure manifest。
- 在最终插入 Word 后逐页检查，而不是只检查单独导出的 PNG。

### 未采用

- 当前报告不是期刊投稿，不执行特定出版社的尺寸、字体、栏宽、CMYK 或印刷分辨率要求。
- 不为了接近“论文图”而增加推断统计；显著性、置信区间和模型结果只能由 CAP-05 的预分析计划与上游证据产生。

## research-skills

本轮复核了 `luwill/research-skills` 的仓库结构和可用方向，但没有安装到当前报告工作流。

- `scholar-slides` 和研究叙事方法适合后续答辩演示，可在 `08_defense` 阶段作为参考。
- `paper-slide-deck` 偏向从论文生成视觉化幻灯片；当前 Word 报告要求数字和中文文本精确可复核，不使用图像生成替代真实图表和文字排版。
- 若进入答辩阶段，将单独评估并记录采用范围，不自动继承本轮报告的审批状态。
