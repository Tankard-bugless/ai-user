## 唯一叙事规则

所有答辩内容必须区分：

- `VERIFIED`：已经真实完成并存在可复核证据；
- `DEMO`：已经在受限场景中实现或验证，不能外推为生产能力；
- `TARGET`：满血版目标架构，尚未全部实现。

“满血版”用于说明最终系统如何设计，不得把 `TARGET` 写成已经上线。
