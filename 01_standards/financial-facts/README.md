# 金融事实库与问卷校对规则

## 1. 定位

金融事实库用于校对研究任务书、问卷、访谈提纲、测试材料和报告中的客观金融表述。V1 先覆盖 FOF、养老目标基金、下滑曲线和个人养老金基金份额；其他领域以后按相同结构增加文件。

它不替代合规审核，不给出投资建议，也不把产品宣传材料直接当作通用事实。

## 2. 来源优先级

1. 现行法律、监管规则和监管机构正式文件。
2. 当前有效的基金合同、招募说明书、产品资料概要和正式公告。
3. 基金管理人的官方投教或产品材料。
4. 行业报告、媒体和内部经验。

低优先级来源可以帮助发现问题和改写通俗语言，但不能单独定义知识题标准答案。若通用规则与具体产品法律文件适用层级不同，应分别表述，不强行合并。

IMA 中的基金管理人官方内容属于第 3 级来源。只有研究人员已读取完整内容、确认发布时间和适用范围，并且与第 1—2 级来源及当前事实库一致时，才可作为 AI 解释的补充来源。接口若只能返回标题，则该结果只属于检索线索，不足以支持事实判断，也不得标为“来源于 IMA”。

## 3. 每次校对的最小流程

1. 从待审版本中抽取所有可判断真假的金融陈述，包括题干、选项、标准答案、AI 解释、学习材料和报告结论。
2. 为每条陈述关联 `fact_id`；找不到对应事实时标记 `FACT_NOT_COVERED`，不得凭模型记忆补答案。
3. 检查事实的 `status`、`verified_at`、适用范围和复核触发条件。
4. 区分通用规则与产品特定规则。涉及费率、持有期、份额、下滑曲线具体数值或产品名录时，必须再核对最新产品法律文件或监管名录。
5. 输出一份版本化审核记录，结论只能是：
   - `PASS`：与当前事实一致。
   - `REVISE`：表述错误、过度绝对或适用范围混淆。
   - `ESCALATE`：来源冲突、规则状态不明或涉及合规判断。
   - `NOT_APPLICABLE`：属于受访者经历、态度或偏好，不是客观金融事实。
6. `REVISE` 或 `ESCALATE` 未关闭前，涉及标准答案、产品资格或交易规则的题目不得通过 Gate 2。
7. 使用 IMA 时记录实际检索词、候选标题、`review_depth` 和链接状态；只检索到标题不能把审核结论从 `REVISE/ESCALATE` 改成 `PASS`。

## 4. 复核触发条件

即使事实库已有记录，出现以下情况仍须重新查询：

- 监管规则、基金合同、招募说明书或产品资料概要更新。
- 问卷加入新的产品、份额类别、费用、持有期或精确比例。
- 事实记录超过 180 天未复核。
- 来源之间出现冲突，或业务方提出与事实库不一致的修改。
- 问卷由通用 FOF 研究改为某只具体基金研究。

## 5. V1 文件

- [`fof-core.v0.1.0.json`](fof-core.v0.1.0.json)：FOF 与养老目标基金首批机器可读事实。

后续扩展建议按领域新增独立文件，例如 `index-fund-core`、`bond-fund-core`，不把所有金融知识堆进一个文件。

## 6. 使用边界

- 知识题必须有一个可核验的最佳答案和“不确定”选项。
- “通常、一般、可能”不能被随意改成“一定、保证、不会”。
- “养老目标基金”“个人养老金可投基金”“Y 类份额”是不同概念，不得互相替代。
- 具体产品费率、持有期和下滑曲线以该产品最新法律文件为准。
- 事实审核记录是研究质量记录，不是正式法律或合规意见。
