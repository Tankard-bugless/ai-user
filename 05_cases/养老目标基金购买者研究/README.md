# 养老目标基金购买者研究

本案例是工作流的首个真实课题演练。研究对象明确限定为已经购买过养老目标基金的投资者，不研究“为什么没有开立个人养老金账户”或“为什么没有缴存”。

## 当前研究命题

**养老目标基金购买者的选择与持有认知调查——聚焦目标日期、目标风险与下滑曲线**

面向参与者时使用更直白的名称：

**您是怎么选择和持有养老基金的？**

## 核心研究链路

实际购买经历 → 当时如何选择 → 是否知道自己买了哪一类 → 是否看过并理解下滑曲线 → 买后如何理解波动与配置变化 → 还需要哪些解释和陪伴

“购买者认知较弱”“很少有人查看下滑曲线”等业务判断只作为待验证假设，不写成问卷前提或研究结论。

## 简化运行边界

本案例只运行以下主链：

研究问题 → 目标受访者画像 → 问卷 → 匿名答卷数据 → 分析 → 报告

工作流只定义“问谁”，不负责寻找、筛选、联系或替换受访者；业务方或外部渠道按画像提供答卷。人工试答和独立访谈也不是本案例的必需步骤。

## 当前执行状态

项目发起人已回传腾讯问卷导出的 200 份 CSV 答卷，字段映射、质量审计、标准化、统计分析和报告生成已经完成。2026-07-28 已将最终报告新增的样本画像、年龄和基金投资经验探索性分析回写为 InsightPackage 0.2.0，并登记 ResearchReport 0.2.0。腾讯问卷在本案例中只承担智能发行、回收和文件导出；平台答案 API、在线统计及平台画像均不是分析依赖。

本次实际运行口径如下：

1. 业务方回传平台导出的原始 CSV；CSV 与 Excel 都属于平台无关的表格回传载体。
2. 工作流按 InstrumentSpec 完成 35/35 个题目的字段映射，并在分析输出中排除 IP、地理位置、设备和浏览器等平台元数据。
3. 200 份答卷均满足同意和购买者甄别条件；没有触发硬排除，但 12 份存在异常短时长信号，94 份存在至少一处平台未执行互斥选项导致的可修复冲突。
4. 互斥冲突按预先公开的规则校正：当“无/不了解/未采取行动”等排他项与实质选项同时出现时，只移除排他项并保留实质选择。
5. 异常短时长记录保留在主分析中，同时执行敏感性分析；关键指标最大变化为 2.2 个百分点。
6. 整体数据状态为 `ANALYSIS_READY_WITH_LIMITS`，表示可以形成方向性结论，但必须披露平台逻辑缺失、来源渠道未知及非概率样本等限制。

本次没有补造正式 Gate 2、Gate 3 或 Gate 4 审批记录。三个追溯登记产物均保持 `DRAFT`，并使用机器可校验的 `governance_gap` 明确历史缺口。控制层只应用真实 Gate 1，当前停在 `GATE_2_REVIEW / WAITING_GATE`；执行包、洞察包和报告在 Registry 中标记为 `STALE`，表示不能绕过 Gate 推动当前流程。当前报告属于内部展示稿，外发前仍需有权限人员针对当前精确版本完成人工审核。

## Gate 1 分群分析预案

- 当前只设一个主要分群：年龄段。
- 区间为 18—29 岁、30—39 岁、40—49 岁、50—59 岁、60 岁及以上，并允许“不愿回答”。
- 只预设三类比较：购买信息渠道与决策角色、产品类型及下滑曲线认知、信息需求与呈现偏好。

- 基金投资经验、产品类型和决策方式仍是研究变量，但本轮不把它们并列为基础人口分群。

## ResearchPlan 摘要

- 研究方法：一份远程自填问卷，不增加独立访谈。
- 问卷结构：购买经历、产品类型认知、下滑曲线、决策因素、持有行为、信息需求。
- 受访者组织：由业务方或外部渠道负责；系统只维护画像口径。
- 分析方法：题目级人数与比例、多选频次、知识题正确情况，以及预定义维度的方向性交叉表。
- 年龄比较：只比较购买信息渠道与决策角色、产品类型/下滑曲线认知、信息需求/形式/时点。
- 结论边界：不加权、不做总体比例、显著性或因果推断。
- 质量保障：自动检查题目追溯、选项、跳转、变量、缺失值和金融表达；人工试答关闭。
- 数据状态：问卷设计时定义 `UNASSESSED → VALID/REVIEW_REQUIRED/EXCLUDED`，回收后执行，不临时发明排除规则。
- IMA：只在问卷完成页提供可选学习链接，不作为研究证据。

## 问卷设计结果

- 当前结果对应 ResearchBrief、ResearchPlan 和 InstrumentSpec 0.2.0。
- 参与者端共 35 个可作答项：C0 同意、S1 购买经历甄别、原 31 道正式题、Q9A 五点信息清晰度和 Q32 年龄段。
- 先测量既有认知和是否查看、使用过下滑曲线，再出现概念知识题，避免题目本身先向受访者提供答案。
- 四道知识题分别形成“产品类型知识得分”和“下滑曲线知识得分”，均允许选择“不确定”。
- Q9A 只测主观信息清晰度，不代替知识题；Q32 只收年龄区间，并允许不愿回答。
- 不采集姓名、联系方式、账户、金额或持仓截图；基金名称为选填且只作自报辅助信息。
- 文档附录包含跳转、变量、知识题答案、报告映射、题目值语义、答卷状态、原因码、数据集状态及发布前检查项。

## 数据有效性与输出状态

问卷与数据规则属于同一个 InstrumentSpec，不是数据回来后再补：

1. 题目设计时定义变量、正常值、特殊值、结构性空缺和题目缺失。
2. 数据导入时每份记录先为 `UNASSESSED`。
3. 未同意、明确未购买、无实质数据、无法修复的版本错误和确认重复可进入 `EXCLUDED`。
4. 购买资格不确定、异常时长、逻辑冲突、疑似重复和高缺失只进入 `REVIEW_REQUIRED`，不能按单一信号自动删除。
5. 人工解决全部复核后，主分析只纳入 `VALID`。
6. 整体数据集输出 `ANALYSIS_READY`、`ANALYSIS_READY_WITH_LIMITS` 或 `BLOCKED`。

知识题答错或不确定、年龄不愿回答和开放题不填写，都不会单独导致答卷无效。

## 分析与报告输出

CAP-05 已按 ResearchPlan 的六个研究问题生成基础统计、Finding、Insight 和 Recommendation。报告首先回应本课题，同时设置独立的“投资者教育建议”板块：

- Q17—Q20 支持识别产品类型和下滑曲线的具体认知缺口。
- Q21—Q25 支持理解持有期行为、波动情境和仍未解决的信息问题。
- Q26 支持排列候选投教内容重点。
- Q27 支持提出候选表达形式。
- Q28 支持提出候选触达时点。
- Q29 补充预设选项没有覆盖的学习问题。
- Q32 只用于按预设年龄段作方向性比较。

投教板块必须引用已经形成的 Insight 和 `INVESTOR_EDUCATION` Recommendation，并明确“偏好某种内容、形式或时点”不等于“该投教方式已经被证明有效”。报告不得给出产品推荐、收益暗示或适当性判断；IMA 只可作为可选学习入口。

可视化优化版不重算数据、不新增洞察，也不提高结论强度。它将购买决策、知识正确率、下滑曲线、投教偏好和年龄描述性差异分别组织为 5 张结论式图表；每张图均保留口径边界、来源清单和替代文本。自然行为、提示后自报和知识正确率没有被画成同一转化漏斗，年龄热力图也明确只作描述性比较。

## 本次数据结果

- 200 份答卷全部进入主分析，没有硬排除；数据集状态为 `ANALYSIS_READY_WITH_LIMITS`。
- 四道核心知识题全部答对者占 20.0%；目标日期与目标风险两题均答对者占 39.5%，说明购买经历不能直接等同于稳定的产品类型和风险边界理解。
- 只有 3.5% 的受访者表示购买时主动比较过下滑曲线，但在问卷提供概念提示后，51.0% 自报其会影响产品判断；“实际使用”与“提示后认同”必须分开解释。
- 59.5% 从未见过下滑曲线或想看但未找到；持有期最需要补充的是未来配置变化、当前配置与风险，以及为什么会调整。
- 投资者教育宜优先使用与年龄或退休年份相连的例子、配置比例表和一句话解释，在首次了解、配置变化及市场波动时提供；IMA 仅作为次级可选学习入口。
- 年龄比较只作描述性方向判断。样本来源渠道和抽样框未知，因此不加权、不做总体比例、显著性或因果推断。
