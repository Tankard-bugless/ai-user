# 问卷题型与测量设计参考

## 1. 使用目的

本文件为 CAP-01、CAP-03、CAP-04 和 CAP-05 提供统一的轻量问卷口径。题型选择由研究问题和预定分析决定，不以“题型丰富”为目标。

V1 借鉴 Knowledge–Attitude–Practice（KAP）结构，但只把它作为组织问题的启发式框架，不把医疗或公共卫生领域的量表效度直接迁移到金融研究。

## 2. V1 轻量测量框架

| 测量维度 | 要回答的问题 | 优先题型 | 不能替代 |
|---|---|---|---|
| Behavior 行为 | 用户实际做过什么、何时做、如何选择 | 单选、多选、具体事件题 | 未来意向不能替代真实行为 |
| Knowledge 认知 | 用户是否知道或能否正确识别概念边界 | 有“不确定”的单选知识题 | 自报“我很了解”不能替代正确作答 |
| Perception / Attitude 感受与态度 | 信息是否清楚、困难程度、主观感受 | 5 点评分题 | 主观清晰度不能替代客观理解 |
| Profile 画像变量 | 本次研究需要比较哪些基础人群 | 分类单选题 | 不自动成为客户标签 |
| Open Exploration 开放探索 | 预设选项遗漏了什么 | 少量选填开放题 | 单个原话不能直接成为共同结论 |

默认题序为：同意 → 最近一次具体行为 → 既有认知 → 客观知识 → 主观评分 → 信息需求 → 基础画像 → 结束。基础画像除非用于纳入或跳转，否则放在问卷后部。

## 3. Demo 题型工具箱

| 题型 | 适用场景 | 最小规则 | 腾讯问卷映射 |
|---|---|---|---|
| 单选题 | 唯一状态、类别、最近一次行为、知识题 | 选项互斥且尽量穷尽；必要时给“不确定/不愿回答” | `[单选题]` |
| 多选题 | 同时发生的行为、信息来源、复合需求 | 说明最多选几项；“没有/记不清/以上都没有”与其他项互斥 | `[多选题]` |
| 5 点评分题 | 清晰度、难度、满意度、信心等程度 | 两端有明确文字锚点；方向全卷一致；中点表示中性而非“不知道” | `[量表题]`，范围 `1~5` |
| 排序题 | 必须获得完整优先级且候选项较少 | 原则上不超过 5 项；移动端负担较高，Demo 优先改为“最重要一项” | `[排序题]` |
| 单行文本题 | 名称、简短补充且确有分析用途 | 默认选填；不得索取账户、联系方式或精确资产信息 | `[单行文本题]` |
| 多行文本题 | 发现遗漏需求或收集解释 | 每份问卷通常保留 1 道选填题 | `[多行文本题]` |
| 矩阵评分题 | 3–5 个项目使用完全相同的量表 | 仅在确有共同构念和手机端可读时使用；V1 默认不用大型矩阵 | `[矩阵量表题]` |

## 4. 题型选择规则

1. 先写出变量及分析用途，再选择题型；没有分析用途的题不进入问卷。
2. 测量事实和最近一次行为时优先用具体单选，不用同意/不同意陈述。
3. 多选题只在答案确实可以同时成立时使用；需要优先级时增加“最重要一项”，不要仅依赖勾选次数。
4. 5 点评分用于程度，不用于判断金融知识正误；“不确定/不适用”应与量表中点分开处理。
5. 知识题必须有经审核的事实依据、一个最佳答案和“不确定”，不得把产品推荐或收益判断写成标准答案。
6. 选项保持同一抽象层级，不混合账户、份额、产品、渠道等不同概念。
7. 一题只测一个核心概念；避免双重问题、模糊时间、否定套否定和暗含前提。
8. 有顺序的等级选项按自然顺序展示，不随机；无顺序且可能受位置影响的长列表可在平台支持时随机。

## 5. Gate 1 分群分析预案

Gate 1 只确认“为什么分群、按什么分、准备比较什么”，不提前写具体问卷题目。每个项目至少指定一个主要分群变量；更多变量只有在明确支持研究问题时才增加。

Demo 的最低字段为：

- `primary_segment.variable_id`
- `primary_segment.categories`
- `primary_segment.rationale`
- `intended_comparisons`
- `analysis_boundary`

### 年龄分群默认示例

| 编码 | 年龄段 |
|---|---|
| AGE-18-29 | 18–29 岁 |
| AGE-30-39 | 30–39 岁 |
| AGE-40-49 | 40–49 岁 |
| AGE-50-59 | 50–59 岁 |
| AGE-60-PLUS | 60 岁及以上 |
| AGE-PREFER-NOT | 不愿回答 |

年龄以区间收集，不收出生日期或精确年龄。年龄分群只用于本项目的方向性比较；小组人数不足时合并或不展示，不形成正式客户标签。

## 6. 来源与采用说明

- WHO 的 KAP 指南用于借鉴“认知—态度—行为—人口特征”的组织方式，不直接复用其领域题库或效度结论：<https://www.who.int/publications/i/item/9789241596176>
- UK Government Analysis Function 建议使用至少 5 点 Likert 量表测量程度，并保持量表方向一致；V1 采用 5 点而非 7 点以降低 Demo 负担：<https://analysisfunction.civilservice.gov.uk/policy-store/questionnaire-design-guidance/>
- Pew Research Center 关于清晰措辞、单一概念、互斥且尽量穷尽的选项、题序效应和人口题后置的规则被采用：<https://www.pewresearch.org/writing-survey-questions/>
- 腾讯问卷 DSL 当前支持单选、多选、量表、排序、文本和矩阵等题型；平台能力只决定实现方式，不改变研究语义。
