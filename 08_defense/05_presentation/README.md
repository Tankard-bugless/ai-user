## 演示原则

- 先展示完整研究路径，再按需进入专家提示词页。
- 面向业务听众使用研究语言，不展示底层接口名称和实现编号。
- AI负责结构化理解、生成、校验、分析和表达；研究人员保留问题判断、风险审核和业务决策。
- 养老目标基金购买者研究只作为已运行案例，不把单一案例写成工作流的适用边界。
- IMA 只作为可选知识与学习材料入口，不承担客户信息存储，也不进入研究证据链。
